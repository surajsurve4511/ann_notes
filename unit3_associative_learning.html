Topic 1

Associative Learning & Memory

The foundation of all recurrent networks. Learning to store and retrieve patterns.

💡 What is Associative Learning?
📖
Definition: A learning paradigm in which a neural network learns to associate one pattern with another (or with itself). When presented with a partial or noisy input, the network retrieves the complete stored pattern.

Biological Basis: Hebb's postulate — "Neurons that fire together, wire together." If neuron A repeatedly causes neuron B to fire, the synapse between A and B is strengthened.

// Hebbian Learning Rule Δwij = η · xi · xj where: η = learning rate xi = activation of presynaptic neuron i xj = activation of postsynaptic neuron j
🔀 Types of Associative Learning

Auto-Associative

Pattern → Same Pattern

Input and output are the same pattern. Given a noisy/incomplete version of a stored pattern, recall the original.

Example: Hopfield Network

  • Input = Output target
  • Used for pattern completion
  • Content-addressable memory

Hetero-Associative

Pattern A → Pattern B

Input and output are different patterns. Learn a mapping between two sets of patterns.

Example: Linear Associator

  • Input ≠ Output
  • Used for pattern transformation
  • Bidirectional Associative Memory
💡
Exam Tip: Auto-associative = Hopfield (recall same pattern). Hetero-associative = Pattern Association task. Always state this distinction clearly.
🧠 Associative Memory

Content-Addressable Memory (CAM): Unlike RAM (accessed by address), associative memory is accessed by the content itself. A partial or noisy key retrieves the full stored item.

Storage Phase

  • Present each pattern to network
  • Update weights using Hebbian rule
  • Weights encode pattern correlations
  • W = Σμ xμ(xμ)T

Retrieval Phase

  • Present probe (partial/noisy)
  • Apply update rule iteratively
  • Network evolves to stable state
  • Stable state = stored pattern
// Hetero-associative weight matrix W = Σμ=1P bμ · (aμ)T Retrieval: y = sign(W · x) // For P stored pairs (aμ, bμ)

Topic 2 — Most Repeated

Hopfield Network

A recurrent auto-associative memory network. Energy-based, guaranteed convergence.

🏗️ Architecture
  • N neurons, fully interconnected (recurrent)
  • Symmetric weights: wij = wji
  • No self-connections: wii = 0
  • Binary states: si ∈ {−1, +1} (bipolar)
  • Single-layer, no hidden neurons
  • All neurons are both input and output
Hopfield Network (N=4)
⚖️ Weight Learning Rule (Hebbian / Outer Product)
// Store P patterns: x¹, x², ..., xᴾ (each xᵢ ∈ {−1, +1}) wij = (1/N) Σμ=1P xᵢμ · xⱼμ for i ≠ j wii = 0 (no self-connection) // Matrix form: W = (1/N) Σμ xμ(xμ)T − (P/N)I
💡
Exam Tip: The weight matrix is symmetric (W = Wᵀ) and has zero diagonal. These two properties guarantee convergence of the asynchronous update rule.
🔄 Update Rule
// Net input to neuron i: neti = Σj≠i wij · sj // State update (hard-limiter / sign function): si(t+1) = +1 if neti > 0 si(t+1) = −1 if neti ≤ 0 si(t+1) = si(t) if neti = 0 (tie-breaking)

Asynchronous Update

One randomly chosen neuron updated at a time. Guaranteed convergence to a stable state (energy strictly decreases). Used in practice.

Synchronous Update

All neurons updated simultaneously. May oscillate between two states (2-cycle). Faster but not guaranteed to converge.

⚡ Energy Function — The Core Concept

The Hopfield network is an energy minimization system. The energy can only decrease or stay the same with each update, so the network always converges.

// Lyapunov (Energy) Function: E = − ½ Σi Σj wij · si · sj // With thresholds θᵢ: E = − ½ Σi Σj wij · si · sj + Σi θᵢ · si // Key property: ΔE ≤ 0 at every asynchronous update ∴ Network converges to a local energy minimum
Energy Landscape — Attractors & False Minima
⚠️
Important: Stored patterns become local energy minima (attractors). Convergence is guaranteed with asynchronous updates because energy is a Lyapunov function.
📉 Storage Capacity & Error Performance
// Maximum reliable storage capacity: Pmax ≈ 0.138 N ≈ 0.14N ≈ N/7 // Crosstalk (interference) noise term: τᵢμ = (1/N) Σν≠μ Σj≠i xⱼν · xⱼμ · xᵢν // Noise variance grows as P/N // Signal-to-Noise ratio ∝ N/P → decreases as P increases

P < 0.14N

✓ Reliable retrieval. Low crosstalk noise.

P ≈ 0.14N

⚠ ~1% error rate. Near capacity limit.

P > 0.14N

✗ Catastrophic failure. Cannot retrieve patterns reliably.

👻 Spurious States (False Minima)

Besides the P stored patterns, the network develops extra attractor states that were not explicitly stored. These are called spurious states or spurious attractors.

// For bipolar patterns, if x¹ and x² are stored, // then their MIXTURE and NEGATIONS are also attractors: Mixture: m = sign(x¹ + x² + x³) (3-mixture spurious state) Negation: If x¹ is stored, -x¹ is also an attractor
  • Spurious states have higher energy than stored patterns
  • Arise from pairwise correlations between stored patterns
  • Number grows exponentially with P
  • Represent incorrect "memories" — false recall
  • Solution: Use unlearning (Hopfield et al.), or simulated annealing
💡
Exam Tip: Spurious states = False minima. They exist because energy minimization is the goal, not pattern storage specifically. The −xμ (complement) of every stored pattern is always a spurious attractor in bipolar networks.
Topic 3 — Appeared Every Year

Simulated Annealing

A probabilistic optimization technique inspired by metallurgy that escapes local minima.

🔬 Physical Analogy

Physical Annealing: Metal is heated to high temperature (atoms move freely), then cooled slowly. Slow cooling allows atoms to settle into the lowest energy crystalline structure (global minimum). Fast cooling = defects (local minima).


Computational Analogy: Replace metal with a combinatorial system. Temperature T controls the randomness. High T = explore widely; Low T = refine solution. Gradually reduce T.

Cooling Schedule
📋 Algorithm (Step by Step)
  1. Initialize the system in a random state s and set a high initial temperature T = T₀
  2. Randomly select a neuron/variable i and compute the energy change ΔE if its state is flipped
  3. If ΔE < 0 (energy decreases): always accept the change (move downhill)
  4. If ΔE ≥ 0 (energy increases): accept with probability P = exp(−ΔE/T) (Metropolis criterion)
  5. Repeat steps 2–4 many times (enough for equilibrium at this temperature)
  6. Reduce temperature: T ← α × T (geometric cooling, α ∈ (0.8, 0.99))
  7. Repeat steps 2–6 until T ≈ 0 or system is frozen
📖
Metropolis Criterion: Accept an uphill move (worsening change) with probability P = exp(−ΔE/T). At high T, almost all moves accepted. At low T, very few uphill moves accepted. This is the key innovation that allows escaping local minima.
🧮 Key Formulas
// Acceptance probability (Metropolis): P(accept) = exp(−ΔE / T) if ΔE > 0 P(accept) = 1 if ΔE ≤ 0 // Geometric cooling schedule: T(k) = α · T(k−1) where α ∈ (0.8, 0.99) // Logarithmic cooling (theoretically optimal): T(k) = T₀ / ln(1 + k) // At high T: P ≈ 1 (random walk, explores freely) // At low T: P ≈ 0 (rare uphill, mostly greedy) // As T → 0: Reduces to gradient descent / Hopfield
📊 Behavior at Different Temperatures
TemperatureAcceptance of worse movesBehaviorResult
Very High T~100%Random walkExplores entire state space
Medium TModerateBiased random walkCan escape shallow minima
Low TRarelyMostly greedy descentConverges to good local min
T → 0NeverDeterministic descentPure Hopfield behavior
💡
Exam Tip: If asked "why does SA avoid local minima?" — Answer: because the Metropolis criterion allows uphill moves with probability exp(−ΔE/T) > 0. This means the system can climb out of local energy wells and eventually find the global minimum if cooling is slow enough.

Topic 4 — Very Important

Boltzmann Machine & Learning

A stochastic recurrent network that learns probability distributions over data.

🏗️ Architecture

A Boltzmann Machine is essentially a stochastic (probabilistic) version of the Hopfield Network with both visible and hidden units.

Visible Units (V)

  • Interface with observed data
  • Clamped during positive phase
  • Free during negative phase
  • Represent data features directly

Hidden Units (H)

  • Not directly observed
  • Learn internal representations
  • Capture higher-order statistics
  • Always free to update
Boltzmann Machine Architecture
🎲 Stochastic Activation

Unlike Hopfield (deterministic), Boltzmann units fire probabilistically. Temperature T controls randomness.

// Probability that unit i is ON (s_i = 1): P(si = 1 | all others) = σ(neti / T) = 1 / (1 + exp(−neti / T)) // Net input: neti = Σj≠i wij · sj + θi (θᵢ = bias) // Temperature effects: T → 0: σ → step function → Deterministic (Hopfield) T → ∞: P(s=1) → 0.5 → Random (coin flip) T = 1: Standard sigmoid activation
⚡ Energy Function & Boltzmann Distribution
// Energy (same as Hopfield): E(s) = − Σi<j wij · si · sj − Σi θi · si // At thermal equilibrium, follows Boltzmann distribution: P(s) = exp(−E(s) / T) / Z // Z = partition function (normalizing constant): Z = Σall s exp(−E(s) / T) // Lower energy states are exponentially more probable
📖
Key Insight: The network naturally settles into a probability distribution over all states. Low-energy states have high probability. By adjusting weights, we can make the network's distribution match the data distribution — this is Boltzmann Learning.
📚 Boltzmann Learning Rule

The goal: adjust weights so the model's equilibrium distribution matches the data distribution. Derived by minimizing KL divergence.

// Weight update rule: Δwij = η · ( ⟨si · sj⟩+ − ⟨si · sj⟩− ) where: ⟨si·sj⟩+ = time-averaged correlation in POSITIVE phase (clamped) ⟨si·sj⟩− = time-averaged correlation in NEGATIVE phase (free) η = learning rate // Bias update: Δθi = η · ( ⟨si⟩+ − ⟨si⟩− )

⊕ Positive Phase (Clamped)

  • Visible units fixed to training data
  • Hidden units run freely to equilibrium
  • Measure ⟨sᵢsⱼ⟩₊ at thermal equilibrium
  • Represents: "What the data requires"
  • Network is "dreaming with data"

⊖ Negative Phase (Free-running)

  • All units (visible + hidden) run freely
  • System reaches thermal equilibrium
  • Measure ⟨sᵢsⱼ⟩₋ at thermal equilibrium
  • Represents: "What the model generates"
  • Network is "dreaming without data"
💡
Exam Tip: The update rule subtracts the model's spontaneous correlations from the data-driven correlations. If the model already matches data, ⟨sᵢsⱼ⟩₊ = ⟨sᵢsⱼ⟩₋ and Δwᵢⱼ = 0 — learning stops. This is elegantly self-regulating.
🔷 Restricted Boltzmann Machine (RBM)

A simplified Boltzmann Machine where only visible–hidden connections are allowed. No V–V or H–H connections.

Advantages

  • Exact computation of gradients
  • Faster training (no H-H correlations)
  • Foundation of Deep Belief Networks
  • Training via Contrastive Divergence

vs Full BM

  • Full BM: all-to-all connections
  • RBM: bipartite structure only
  • Full BM: MCMC for learning
  • RBM: Contrastive Divergence (CD-1)
Topic 5

Stochastic Networks & State Transitions

Understanding dynamics of neural networks through energy landscapes and state diagrams.

🗺️ State Transition Diagram
📖
Definition: A directed graph where each node represents a possible system state (binary vector) and each edge represents a possible transition. Fixed points (no outgoing edges to different states) are attractors.
  • States: All 2N possible binary configurations
  • Transitions: Determined by update rule (deterministic or probabilistic)
  • Fixed Points: States that map to themselves — attractors
  • Limit Cycles: States that cycle (possible in sync update)
  • Basin of Attraction: Set of states that converge to the same attractor
  • False Minima: Fixed points that are NOT stored patterns
State Transition (N=2 example)
👻 False Minima Problem

False minima (spurious attractors) are unintended stable states. They arise because the energy function has more minima than the number of stored patterns.

TypeDescriptionSolution
Complementary−xμ is always an attractor in bipolar networksUse unipolar units (0/1)
Mixture statesLinear combinations ±xα±xβ±... become attractorsReduce storage P or use unlearning
Spin-glass statesRandom frozen states with no relation to training dataKeep P < 0.14N
⚠️
Key Problem: A network initialized with a probe pattern may converge to a spurious state instead of the intended pattern — this is an incorrect retrieval. The probability of this increases as P approaches capacity.
🎲 Stochastic Update

In stochastic networks, updates are probabilistic rather than deterministic. This introduces randomness that helps escape local minima.

// Stochastic update rule (Boltzmann): P(si = +1) = 1 / (1 + exp(−2·neti / T)) // For bipolar units, or equivalently: P(si = 1) = σ(neti / T) (for binary 0/1 units) // As T → 0: Deterministic (Hopfield behavior) // At T > 0: Probabilistic (Boltzmann behavior)

T = 0 (Deterministic)

si = sign(neti). Always go to lower energy. Gets stuck in local minima. Hopfield behavior.

T > 0 (Stochastic)

Occasionally accept worse states. Can escape local minima. Used in Boltzmann Machine and Simulated Annealing.

Topic 6

Pattern Recognition Tasks

Three fundamental tasks of ANN-based pattern recognition, plus catastrophic forgetting.

🔁 Pattern Association
📖
Definition: Given an input pattern from set A, retrieve the associated output pattern from set B. When A = B (same set), it's auto-association. When A ≠ B, it's hetero-association.

Auto-Associative

  • Input = Output space
  • Recall complete pattern from partial
  • Example: Hopfield network
  • W = Σ xμ(xμ)T
  • Given noisy x̃ → retrieve x

Hetero-Associative

  • Input space A → Output space B
  • Given pattern A, recall pattern B
  • Example: Linear Associator
  • W = Σ bμ(aμ)T
  • Given a → y = f(Wa)
// Hetero-associative weight matrix (P pairs): W = Σμ=1P bμ · (aμ)T // Retrieval: y = sign(W · x) // for bipolar y = f(W · x) // for continuous // Example: Face-Name association, Word-Image pairs
💡
Exam: Pattern association stores (input, output) pairs. The key formula is W = Σ bμ(aμ)T. Pattern completion = auto-associative. Cross-modal recall = hetero-associative.
🏷️ Pattern Classification
📖
Definition: Map an input pattern x to a discrete class label c ∈ {1, 2, ..., C}. The network learns decision boundaries that partition the input space into regions corresponding to each class.

Key Characteristics

  • Discrete output (class labels)
  • Learns discriminant functions
  • Supervised learning (labeled data)
  • Output: one-hot or class index
  • Training: error minimization

Examples

  • Perceptron (linear boundary)
  • ADALINE (adaptive linear)
  • MLP (nonlinear boundary)
  • Handwriting recognition
  • Spam / not spam
// General form: f: Rn → {1, 2, ..., C} // Discriminant function for class k: gk(x) = wkT · x + bk // Classification decision: ĉ = argmaxk gk(x) // Linearly separable: Perceptron guaranteed to find boundary // Non-linearly separable: Need MLP / kernel methods
🗺️ Pattern Mapping
📖
Definition: The most general task. Map an input vector x ∈ Rn to a continuous output vector y ∈ Rm. Equivalent to function approximation. Output is real-valued, not discrete.

Key Characteristics

  • Continuous output (real values)
  • Function approximation: f: Rn → Rm
  • Regression-type problem
  • MSE / MAE loss functions
  • Universal approximation theorem applies

Examples

  • Robot arm control (joint angles)
  • Speech synthesis (text → audio)
  • Image-to-image translation
  • Stock price prediction
  • MLP with backpropagation
// General form: f: Rn → Rm (continuous mapping) // Loss function (MSE): L = (1/P) Σμ ||yμ − f(xμ; W)||² // Trained via gradient descent / backpropagation

💡
Exam Tip: Association = retrieve stored pattern. Classification = assign a label (discrete). Mapping = produce a real-valued output. Classification is a special case of mapping where output is quantized to class labels.
💀 Catastrophic Forgetting
📖
Definition: When a neural network trained on task A is subsequently trained on task B, the weights for task A are overwritten and performance on A degrades dramatically — the network "forgets" task A catastrophically.

Why it happens: Gradient descent adjusts all weights based on the new task B's error signal, disrupting the weight configuration that encoded task A.

Problem Severity Factors

  • High learning rate → worse forgetting
  • Similar tasks → less forgetting
  • Small network → more overlap
  • Sequential (not interleaved) training

Solutions

  • Rehearsal: Mix old data into new training
  • EWC: Penalize changes to important weights
  • Progressive Networks: New columns per task
  • Memory Replay: Replay stored examples
// Elastic Weight Consolidation (EWC) loss: L(θ) = LB(θ) + λ/2 · Σi Fi · (θi − θA,i)² where: LB(θ) = loss on new task B θA,i = optimal parameters after task A Fi = Fisher information (importance of weight i for task A) λ = regularization strength // High Fᵢ → that weight is important for A → penalize changes
📝
Note: Catastrophic forgetting is a fundamental limitation of gradient-based learning. It's opposite to biological memory: humans can learn new things without forgetting old ones (usually). This is an active area of research in continual/lifelong learning.

🕸️ Hopfield Network

  • Fully connected, symmetric, wii=0
  • Bipolar neurons {−1, +1}
  • Asynchronous: guaranteed convergence
  • Synchronous: may oscillate
  • Energy decreases monotonically
  • Capacity: ~0.14N patterns
  • Spurious states = false minima
  • Biological: content-addressable memory

🌡️ Simulated Annealing

  • Inspiration: metallurgical annealing
  • Accept worse: P = exp(−ΔE/T)
  • High T → explore; Low T → exploit
  • Geometric cooling: T = αT
  • Avoids local minima (unlike Hopfield)
  • T=0 → reduces to Hopfield
  • Theoretically finds global minimum
  • Metropolis-Hastings criterion

⚡ Boltzmann Machine

  • Visible + Hidden units
  • Stochastic (probabilistic) activation
  • Boltzmann distribution at equilibrium
  • 2 phases: clamped (+) and free (−)
  • Δwᵢⱼ = η(⟨sᵢsⱼ⟩₊ − ⟨sᵢsⱼ⟩₋)
  • RBM: only V-H connections
  • Foundation of deep learning (DBN)
  • Slow to train; theoretically sound

🧩 Pattern Tasks

  • Association: retrieve stored pattern pair
  • Auto: recall own pattern (Hopfield)
  • Hetero: recall paired pattern
  • Classification: discrete label output
  • Mapping: continuous output (regression)
  • Mapping is most general task
  • Catastrophic forgetting = sequential task problem
  • EWC: protect important weights

⭐ Last-Minute Exam Tips
  1. Hopfield energy function = E = −½ΣΣwᵢⱼsᵢsⱼ — write this first in any Hopfield question. Say "this is a Lyapunov function" — this earns marks.
  2. SA algorithm — always mention the Metropolis criterion P = exp(−ΔE/T). Say it reduces to Hopfield when T=0. Mention cooling schedule.
  3. Boltzmann Learning two phases — draw the table: Positive phase (data clamped, hidden free) vs Negative phase (all free). The update rule subtracts them.
  4. Pattern tasks comparison — if asked to compare all three, make a table with: output type, task, network example. This always impresses examiners.
  5. Spurious states — complement −xμ of stored pattern is always a spurious attractor (in bipolar). This is a common Q.
  6. Capacity = 0.14N — always state this. If P > 0.14N → catastrophic failure. If P < 0.14N → reliable retrieval.
  7. Draw diagrams — Hopfield network (circle with bidirectional weights), Boltzmann (visible layer bottom, hidden top), Energy landscape (curve with minima). Diagrams = extra marks.
