Competitive Learning Network

🔥 ALL 3 YEARS
Definition
A Competitive Learning Network is an unsupervised neural network where output neurons compete with each other to be activated. Only one neuron wins (Winner-Takes-All), and its weights are updated to become more like the input.

Core Idea

Neurons specialize over time. Each neuron learns to recognize a specific class of input patterns without any labeled data. This is the basis of all self-organization.

Components of CL Network

Input Layer
  • Receives the input pattern vector X
  • No learning happens here
  • Fully connected to output layer
Output / Competitive Layer
  • Neurons compete for activation
  • Only the winner fires (output = 1)
  • All others suppressed (output = 0)
Weight Vectors
  • Each output neuron has a weight vector W
  • Represent a "prototype" of a cluster
  • Updated only for the winner
Lateral Inhibition
  • Winning neuron inhibits all others
  • Enforces the winner-takes-all rule
  • Implemented via negative connections

Winner-Takes-All (WTA) Rule

The winning neuron j* is the one whose weight vector is closest to the input:

Finding the Winner (Euclidean Distance) j* = argminj ‖ X − Wj ‖
OR equivalently (Dot Product / Net Input) j* = argmaxj ( X · Wj ) [when vectors are normalized]

Weight Update Rule

Only the winner's weights are updated ΔWj* = α · (X − Wj*)
Wj*(new) = Wj*(old) + α · (X − Wj*)

α = learning rate (0 < α ≤ 1). This moves the winner's weight vector closer to the input pattern — the neuron "claims" that input.

Training Algorithm

  1. Initialize weight vectors randomly (or normalize to unit length)
  2. Present input pattern X
  3. Compute distances (or dot products) from X to every weight vector
  4. Select winning neuron j* (minimum distance)
  5. Update only j*'s weights: Wj* += α(X − Wj*)
  6. Reduce learning rate α slightly
  7. Repeat steps 2–6 until convergence

Properties

  • Unsupervised — no labels needed
  • Performs automatic clustering of input data
  • Each output neuron becomes a cluster centroid
  • Related to k-means clustering algorithmically
  • Can suffer from "dead neurons" (neurons that never win)
Exam Tip
Always mention: (1) Winner-Takes-All mechanism, (2) Distance formula for finding winner, (3) Weight update only for winner. These are the three core exam points.
02

SOM Architecture

🔥 ALL 3 YEARS
What is SOM?
A Self-Organizing Map (SOM), developed by Teuvo Kohonen (1982), is a competitive network that maps high-dimensional input data onto a low-dimensional (usually 2D) grid while preserving the topological structure of the data.

Two Basic Feature Mapping Models

1. Willshaw-von der Malsburg Model

Biologically inspired model. Neighboring neurons have excitatory connections; far neurons have inhibitory connections. Creates a Mexican Hat function of interaction.

2. Kohonen's SOM Model

Simplified computational model. Uses a neighborhood function instead of explicit lateral connections. More practical and widely used.

Architecture of Kohonen SOM

Key Structural Features

  • Input Layer: N neurons, one per input dimension (no processing)
  • Competitive Layer: 1D or 2D grid of output neurons (typically 2D)
  • Full Connectivity: Every input neuron connects to every output neuron
  • Weight Matrix: Each output neuron j has weight vector Wj of same dimension as input
  • No Output Layer: The competitive layer IS the output
  • Best Matching Unit (BMU): The winning output neuron for a given input

Neighborhood Function

Unlike basic competitive learning, SOM updates not just the winner but all neurons within a topological neighborhood of the winner:

Gaussian Neighborhood Function h(j, j*, t) = exp( −‖rj − rj*‖² / 2σ(t)² )

Where rj = position of neuron j on the map, rj* = position of BMU, σ(t) = neighborhood radius (decreases over time).

Key Insight — Topology Preservation
Neurons that are close on the map will respond to similar inputs. This preserves the topological structure of the input space in the 2D output map — the fundamental difference from basic competitive learning.
03

SOM Algorithm

🔥 2023, 2025
The 3 Phases
SOM training has three processes happening simultaneously: Competition (find BMU) → Cooperation (determine neighborhood) → Adaptation (update weights).

Step-by-Step Algorithm

  1. Initialize: Set weights Wj randomly (small values or random samples from training data). Set initial learning rate α(0) and neighborhood radius σ(0).
  2. Select Input: Choose a training sample X from the dataset (randomly or sequentially).
  3. Competition — Find BMU: Compute Euclidean distance between X and every neuron's weight vector. The neuron j* with minimum distance is the Best Matching Unit (BMU).
    j* = argminj ‖ X − Wj ‖²
  4. Cooperation — Determine Neighborhood: Calculate the neighborhood function h(j, j*, t) for all neurons. Neurons close to BMU on the map get higher h values.
    h(j, j*, t) = exp(−d²j,j* / 2σ²(t))
  5. Adaptation — Update All Weights: Update weights of BMU and its neighbors proportionally to h.
    Wj(t+1) = Wj(t) + α(t) · h(j,j*,t) · [X − Wj(t)]
  6. Decay Parameters: Reduce learning rate and neighborhood radius:
    α(t) = α(0) · exp(−t/τ₁)     σ(t) = σ(0) · exp(−t/τ₂)
  7. Repeat: Go to Step 2 until maximum iterations reached or convergence.

Two Phases of Training

Phase 1: Ordering Phase

Large neighborhood, higher learning rate. The map unfolds to cover the input space. Global topology is established. Runs for ~1000 iterations.

Phase 2: Convergence Phase

Small neighborhood (1–2 neurons), very small learning rate. Fine-tuning of weights. Map becomes statistically accurate. Runs for ~10× more iterations.

Properties of Feature Map (SOM Output)

  • Topographic Ordering: Similar inputs activate nearby neurons on the map
  • Density Matching: More neurons are allocated to regions with more input data density
  • Feature Selection: Map automatically discovers statistical regularities
  • Dimensionality Reduction: High-dimensional data → 2D map (like PCA but nonlinear)
  • Magnification Factor: Areas with more data samples get more map neurons

ART Network

⭐ 2023, 2024
Core Problem Solved
ART solves the Stability-Plasticity Dilemma: How can a network learn new patterns (plasticity) without forgetting old ones (stability)? Basic neural nets forget old patterns when trained on new ones — ART avoids this.

ART = Adaptive Resonance Theory, developed by Grossberg (1987). It is a self-organizing network that creates new categories dynamically as needed, without retraining from scratch.

Features of ART Models

  • Online learning: Can learn new patterns one at a time
  • Stable memory: Previously learned patterns are not erased
  • Dynamic categorization: Creates new categories when no existing one fits
  • Vigilance parameter (ρ): Controls how strict matching must be to assign a pattern to an existing category
  • Two-layer architecture: Comparison layer (F1) and recognition layer (F2)
  • Bottom-up & top-down weights: Both directions of information flow

ART Architecture

Types of ART

TypeInput TypeDescription
ART 1Binary (0/1)Simplest; handles binary patterns only. Uses subset matching.
ART 2Continuous (analog)Handles real-valued inputs. More complex normalization steps.
ARTMAPBinary / ContinuousSupervised version; maps input patterns to target classes.
Fuzzy ARTContinuous [0,1]Uses fuzzy logic operators for matching.

ART 1 Algorithm (Binary)

  1. Present Input X to F1 layer
  2. Compute activation of F2 neurons: Tj = (X · Wbj) / (0.5 + ‖Wbj‖₁)
  3. Select winner j* = argmax Tj (highest activation)
  4. Check Vigilance: Compute match = ‖ X AND Wtj* ‖ / ‖ X ‖
    • If match ≥ ρ → Resonance! Update weights, assign X to category j*
    • If match < ρ → Reset! Inhibit j*, go to step 3 (try next best)
  5. Create New Category if all categories fail the vigilance test
  6. Update Weights on resonance:
    Wbj*(new) = (X AND Wtj*) / (0.5 + ‖ X AND Wtj*‖₁)
    Wtj*(new) = X AND Wtj*

Role of Vigilance Parameter ρ

High ρ (close to 1)

Very strict matching. Creates many fine-grained categories. Less generalization. Patterns must be very similar to belong to same category.

Low ρ (close to 0)

Loose matching. Creates few coarse categories. More generalization. Very different patterns can belong to same category.

05

Character Recognition using ART

⭐ 2023, 2024

ART networks are well-suited for optical character recognition (OCR) because they can learn new characters without forgetting old ones, and can handle slight variations in handwriting.

How It Works

Setup
Input: A character image (e.g., 8×8 or 16×16 pixel grid) → flattened into a binary vector (pixel ON = 1, pixel OFF = 0). Each ART category corresponds to one character class (A, B, C, ...).
  1. Encode the character: Convert the letter/digit image into a binary vector X of length N (= total pixels). For example, the letter 'A' on a 5×7 grid becomes a 35-bit vector.
  2. Present to ART 1: Input vector X is sent to the F1 (comparison) layer.
  3. Find best matching category: F2 neurons compete; the one with weights most similar to X wins.
  4. Vigilance test: Check if the winning category's prototype matches X sufficiently (match ratio ≥ ρ).
  5. Assign or create:
    • Match found: X is assigned to the existing character category; weights updated slightly.
    • No match: A new category is created for this character variant.

Example — Recognizing Noisy Characters

Advantages for Character Recognition

  • Can recognize multiple fonts/handwriting styles as the same character
  • New character sets can be added without retraining the whole network
  • Robust to noise — slightly corrupted images still match correct category
  • ρ can be tuned: low ρ = font-independent recognition; high ρ = font-specific
  • No catastrophic forgetting when new characters/fonts are added

Vector Quantization (VQ)

🔥 ALL 3 YEARS
Definition
Vector Quantization is a lossy data compression technique that maps a large set of input vectors to a smaller set of representative vectors called a codebook. Each input vector is approximated by its nearest codebook entry (codeword).

Core Concepts

Codebook

A set of K prototype vectors {c₁, c₂, ..., cK} that represent the entire input space. Also called codewords or code vectors.

Quantization Error

The distortion introduced by replacing an input X with its nearest codeword. Goal: minimize the average distortion across all inputs.

Voronoi Regions

The input space is partitioned into K regions, one per codeword. All inputs in a region are approximated by that region's codeword.

Compression Ratio

Instead of storing the full vector, only store the index of the nearest codeword. log₂(K) bits instead of N×(bits per value).

VQ Process

  1. Design codebook: Train to find K representative vectors that minimize distortion (using LBG algorithm or neural network)
  2. Encoding: For each input vector X, find the nearest codeword cj*: j* = argminj ‖X − cj‖. Transmit/store only the index j*.
  3. Decoding: Receiver looks up the codebook using the index j* to reconstruct the approximate signal.

VQ and Competitive Learning

A competitive learning network naturally implements VQ! Each output neuron's weight vector acts as a codeword, and training makes these weight vectors distributed optimally across the input space.

VQ Distortion Measure (to minimize) D = (1/N) · Σᵢ ‖ Xᵢ − cq(i) ‖²

where q(i) = index of nearest codeword to Xᵢ

Applications

  • Image Compression: Compress image blocks using a codebook of typical block patterns
  • Speech Coding: Compress speech spectral parameters for transmission
  • Pattern Classification: Use VQ as a pre-processing/feature extraction step
  • Data Clustering: Codebook entries represent cluster centroids

Learning Vector Quantization (LVQ)

⭐ 2024, 2025
What is LVQ?
LVQ is a supervised version of VQ / competitive learning, introduced by Kohonen. Each codebook vector (prototype) has a class label. Classification is done by finding the nearest prototype and assigning its label to the input.

Key Difference: VQ vs LVQ

AspectVQLVQ
Learning typeUnsupervisedSupervised
LabelsNo class labelsEach prototype has a class label
GoalMinimize distortionMinimize classification error
Update ruleMove toward inputMove toward if correct, away if wrong

LVQ Architecture

  • Input layer: One neuron per input feature
  • Competitive layer: M prototype neurons (codewords with class labels)
  • Multiple prototypes can represent the same class
  • Final class = label of nearest prototype

LVQ1 Algorithm (Basic)

  1. Initialize prototype vectors Wj and assign class labels to each
  2. Present input (X, class c(X))
  3. Find nearest prototype j* = argmin ‖X − Wj‖
  4. Update based on classification:
    If label(j*) == class(X) → CORRECT → move closer Wj*(t+1) = Wj*(t) + α(t) · [X − Wj*(t)]

    If label(j*) ≠ class(X) → WRONG → push away Wj*(t+1) = Wj*(t) − α(t) · [X − Wj*(t)]
  5. Reduce α(t) and repeat until convergence

LVQ Variants

LVQ2 / LVQ2.1

Updates two nearest prototypes when input falls in a "window" near the decision boundary. Improves boundary accuracy. One from same class (reward), one from different class (punish).

LVQ3

Like LVQ2.1 but also updates when both nearest prototypes belong to the same class. Prevents prototypes from drifting away from class clusters.

Applications of LVQ

  • Speech recognition (phoneme classification)
  • Medical diagnosis (classify ECG patterns)
  • Adaptive pattern classification in noisy environments
  • Fast classification when training data is large

Feature Mapping & Pattern Clustering

🔥 ALL 3 YEARS

Pattern Clustering

Clustering is the automatic grouping of similar input patterns without labels. Competitive learning networks perform clustering by assigning each pattern to the nearest weight vector (cluster center).

Clustering in Competitive Networks
After training, each output neuron represents a cluster centroid. Patterns that activate the same output neuron belong to the same cluster. This is equivalent to K-means clustering where K = number of output neurons.

Feature Mapping

Feature mapping refers to the process of projecting high-dimensional input space into a lower-dimensional representation while preserving important structure (topology, distances, neighborhood relationships).

What is preserved?
  • Topological neighborhood
  • Relative distances between patterns
  • Statistical regularities
  • Cluster structure
Applications
  • Data visualization
  • Speech feature mapping
  • Sensor fusion
  • Robot sensory-motor mapping

Computer Simulations (SOM Use Cases)

  • Travelling Salesman Problem: SOM finds approximate shortest routes
  • Color Map Generation: Map 3D color space (RGB) to 2D for displays
  • Speech Phoneme Map: SOM of speech features clusters phonemes spatially
  • Kohonen's Phonotopic Map: Different speech sounds map to different spatial regions
  • Dimensionality Reduction: Visualize high-dimensional datasets in 2D

Adaptive Pattern Classification

Using LVQ/competitive networks for classification that adapts over time:

  • Prototypes dynamically move to better represent their classes
  • Decision boundaries adjust as new patterns arrive
  • Combines benefits of unsupervised feature extraction (SOM) with supervised classification (LVQ)
  • Two-stage approach: First SOM for feature mapping, then LVQ for classification

One-Line Definitions (for short answers)

  • Competitive Learning: Winner-takes-all unsupervised learning where only the closest neuron's weights are updated.
  • SOM: A Kohonen network that maps high-dimensional inputs to a 2D topology-preserving grid.
  • BMU: Best Matching Unit — the SOM output neuron with weights closest to the input.
  • ART: Self-organizing network that resolves the stability-plasticity dilemma via a vigilance parameter.
  • Vigilance (ρ): ART parameter controlling how strict the match must be to assign input to existing category.
  • Vector Quantization: Lossy compression mapping inputs to nearest codeword in a trained codebook.
  • LVQ: Supervised VQ where labeled prototypes move toward correct inputs and away from incorrect ones.
  • Feature Map: Low-dimensional representation of input space preserving topological structure.
