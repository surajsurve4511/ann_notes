CNN Architecture

🔥 Hot Topic 2024 ✓ 2025 ✓

A Convolutional Neural Network (CNN) is a class of deep neural network designed specifically to process data with grid-like topology — most commonly images. Unlike traditional MLPs, CNNs exploit spatial locality and parameter sharing to dramatically reduce the number of parameters while preserving spatial structure.

Key Properties of CNNs

Local Connectivity

Each neuron connects only to a small local region of the input (the receptive field), reducing parameters compared to fully connected layers.

Parameter Sharing

The same filter (set of weights) slides across the entire image, meaning features learned in one region apply everywhere.

Translation Invariance

Because the same filter is applied everywhere, CNNs can detect features regardless of their position in the image.

Hierarchical Features

Early layers detect edges → middle layers detect shapes → deep layers detect complex objects.

02

Convolution Layer

The convolution layer is the core building block of a CNN. It applies a set of learnable filters (kernels) to the input by sliding them across the spatial dimensions and computing dot products, producing feature maps.

How Convolution Works

A filter F of size f×f is slid across the input X. At each position, element-wise multiplication is performed and the results are summed, adding a bias b:

Convolution Operation Z[i, j] = Σ Σ W[m, n] · X[i·s + m, j·s + n] + b

where: s = stride, W = filter weights, b = bias
Output Dimension Formula n_out = ⌊ (n_in + 2·p − f) / s ⌋ + 1

where: n_in = input size, p = padding, f = filter size, s = stride

Number of Parameters in a Conv Layer

Parameter Count Parameters = (f × f × n_C_prev + 1) × n_C

where: f = filter size, n_C_prev = input channels, n_C = number of filters
+1 accounts for the bias term per filter
💡
Key Insight

Regardless of input image size, the number of parameters in a conv layer depends only on filter size and number of channels — not on the image dimensions. This is the power of parameter sharing.

Average Pooling

Takes the average value in each pooling window. More common in later layers (e.g., Global Average Pooling before FC).

Key Properties of Pooling

No Parameters

Zero learnable weights. Just a fixed mathematical operation — max or average over a window.

Reduces Dimensions

With pool size f=2, stride s=2, the spatial dimensions are halved: n × n → n/2 × n/2.

Depth Unchanged

Pooling operates independently on each channel. The number of channels (depth) stays the same after pooling.

Pooling Output Dimension n_out = ⌊ (n_in − f) / s ⌋ + 1
(same formula as conv but typically no padding in pooling)
📝
Exam Tip

Always mention: Pooling has NO learnable parameters. Max pooling retains the dominant feature in the region, making it robust to small translations in the input.

Padding & Strided Convolutions

2023 ✓

Padding

Padding adds extra pixels (usually zeros) around the border of the input before convolution. This addresses two problems: (1) the output shrinks with each conv layer, and (2) corner/edge pixels are used far less than central pixels.

Valid Padding (p=0)

No padding applied. Output is smaller than input.

n_out = n − f + 1

Same Padding

Output has the same spatial dimensions as input.

p = (f − 1) / 2
💡
Why odd-sized filters?

Filters in CNNs are almost always odd-sized (1×1, 3×3, 5×5, 7×7). This ensures that Same padding p = (f−1)/2 is always an integer, and there is a defined center pixel for the filter.

Strided Convolutions

The stride s controls how many pixels the filter moves at each step. A stride of 1 moves 1 pixel at a time (dense), while stride 2 skips every other position (downsampling).

Stride Effects at a Glance

Stride s = 1Dense, more computation, larger output
Stride s = 2Downsamples by ×2, reduces computation
Large strideCan replace pooling for downsampling
05

Convolutions over Volumes

Real images are 3-dimensional: height × width × channels (e.g., RGB = 3 channels). Filters must also be 3-dimensional with the same depth as the input.

3D Convolution Input: n × n × n_C
Filter: f × f × n_C (depth must match input depth)
Output: n_out × n_out × 1 (per filter)

With n_C' filters → output: n_out × n_out × n_C'

Multiple Filters → Multiple Feature Maps

Each filter detects a different kind of feature (vertical edges, horizontal edges, curves, etc.). The outputs of all filters are stacked depth-wise, creating a volume of feature maps.

💡
Critical Rule

The filter depth must ALWAYS equal the input depth (n_C). A 3-channel RGB input needs f×f×3 filters. A 64-channel feature map needs f×f×64 filters.

1×1 Convolutions (Network-in-Network)

A 1×1×n_C filter acts on a single pixel across all channels. It's used to: (1) reduce or increase channel depth, (2) add nonlinearity via ReLU, and (3) compress feature maps cheaply (used in Inception and ResNet bottleneck layers).

06

Flattening Layer

2024 ✓

The flattening layer acts as the bridge between convolutional layers and fully connected layers. It converts the 3D tensor output of the last pooling/conv layer into a 1D vector.

Flatten Operation Input: h × w × c (3D feature map)
Output: (h × w × c,) (1D vector of length h·w·c)

Example: 7 × 7 × 512 → 25,088-dimensional vector
⚠️
No Computation

Flattening is purely a reshape operation — no weights, no activations, no learned parameters. It simply unrolls the multi-dimensional tensor into a flat array for the FC layers.

SoftMax Regression

2023 ✓

SoftMax is the activation function used in the final output layer for multi-class classification. It converts a vector of raw logit scores into a probability distribution over C classes.

SoftMax Function σ(z)_i = e^(z_i) / Σ(j=1 to C) e^(z_j)

Properties:
→ All outputs are in range (0, 1)
→ Sum of all outputs = 1
→ Largest z_i gets the highest probability
Raw Logits
z = [2.1, 0.5, 3.2]
→
exp(z)

→
Probabilities
[0.24, 0.05, 0.71]

Loss Function: Cross-Entropy

Categorical Cross-Entropy Loss L = −Σ y_i · log(ŷ_i)

where y is the one-hot true label and ŷ is the predicted probability
💡
Sigmoid vs SoftMax

Use Sigmoid for binary classification (outputs independent probabilities) and SoftMax for multi-class classification (outputs mutually exclusive probabilities that sum to 1).

Bias & Variance Tradeoff

🔥 Hot Topic 2024 ✓ 2025 ✓

Bias measures how far off the model's predictions are from the true values (error due to wrong assumptions). Variance measures how much the model's predictions vary for different training sets (sensitivity to noise).

High Bias (Underfitting)

Train Error: ~15% | Dev Error: ~16%
  • Model is too simple
  • Cannot capture patterns
  • Fails even on training data
Fix: Bigger network, more layers, train longer

High Variance (Overfitting)

Train Error: ~1% | Dev Error: ~15%
  • Model memorized training data
  • Poor generalization
  • Large train-dev gap
Fix: More data, regularization, dropout

High Bias + High Variance

Train Error: ~15% | Dev Error: ~30%
  • Worst case scenario
  • Underfits in some regions
  • Overfits in others
Fix: Larger model + regularization

Low Bias + Low Variance

Train Error: ~1% | Dev Error: ~2%
  • Ideal scenario
  • Generalizes well
  • Small train-dev gap
Goal to achieve!

With Mismatched Data Distributions

When training data and dev/test data come from different distributions (e.g., training on internet photos, testing on mobile camera photos), we need a more careful analysis:

ScenarioTrain ErrorTrain-Dev ErrorDev ErrorDiagnosis
Case 11%2%10%Data mismatch problem
Case 21%10%11%Variance (overfitting)
Case 310%11%12%Bias (underfitting)

Regularization Techniques to Fix Variance

L2 Regularization

Adds λ·‖W‖² to the loss. Penalizes large weights, preventing overfitting.

Dropout

Randomly deactivates neurons during training with probability p. Forces redundant representations.

Batch Normalization

Normalizes layer inputs. Reduces internal covariate shift, acts as mild regularizer.

Data Augmentation

Flips, crops, rotations, color jitter artificially expand the training set.

Transfer Learning

2023 ✓

Transfer learning is a technique where a model pre-trained on a large dataset (e.g., ImageNet with 1.2M images) is reused for a different but related task. This is especially valuable when the target dataset is small.

Pre-train

Train deep CNN on large dataset (ImageNet). Model learns general features: edges, textures, shapes.

Adapt

Remove last FC layer(s). Freeze early layers. Add new FC layers matching target classes.

Fine-tune

Train on small target dataset. Only new layers (or all layers) update based on data size.

When to Freeze vs Fine-tune

Target Data SizeStrategyApproach
Very Small (<1K samples)Feature ExtractionFreeze all layers; train only new output layer
Medium (1K–100K)Partial Fine-tuningFreeze early layers; fine-tune last few layers
Large (>100K)Full Fine-tuningInitialize from pre-trained; retrain entire network
💡
Why it works

Early CNN layers learn universal features (edges, curves) that apply to almost any vision task. Only the later layers encode task-specific features that need to be retrained.

10

Multi-task Learning

Multi-task learning trains a single neural network to perform multiple tasks simultaneously, sharing lower-level representations. A classic example is an autonomous driving system that simultaneously detects pedestrians, cars, traffic signs, and traffic lights.

When to Use Multi-task Learning

  • Tasks share similar low-level features (e.g., all are visual recognition tasks)
  • Amount of data per task is similar
  • A large enough network can handle all tasks
  • Training a shared model is more practical than separate models

Multi-task Loss

Multi-Task Loss L = (1/m) Σ_i Σ_j L(ŷ_i^(j), y_i^(j))

Sum over all training examples (i) and all tasks (j)
Missing labels can be ignored during backprop
11

End-to-End Deep Learning

End-to-end deep learning replaces a multi-stage processing pipeline with a single neural network that directly learns from raw input (e.g., audio waveform) to final output (e.g., text transcript).

Pros

  • Less hand-engineering and domain knowledge required
  • Learns from data directly
  • Can discover optimal features automatically

Cons

  • Requires very large labeled datasets
  • Cannot leverage existing domain knowledge
  • Less interpretable

AlexNet

🔥 Hot Topic 2024 ✓ 2025 ✓

Proposed by Alex Krizhevsky, Ilya Sutskever, and Geoffrey Hinton in 2012, AlexNet won the ImageNet ILSVRC-2012 competition with a top-5 error of 15.3% — dramatically better than the runner-up (26.2%). It reignited interest in deep learning and is considered a watershed moment in AI history.

Key Innovations in AlexNet

ReLU Activation

First large-scale use of ReLU instead of sigmoid/tanh. Trained 6× faster and solved the vanishing gradient issue.

Dropout (0.5)

Applied to FC layers to prevent overfitting. Randomly drops 50% of neurons during training.

Data Augmentation

Random crops, horizontal flips, and color jittering to artificially expand the training set.

Multi-GPU Training

Split across 2 GTX 580 GPUs (only 3GB VRAM each). Used inter-GPU communication at certain layers.

LRN (Local Response Normalization)

Normalizes responses across adjacent feature maps. Enhances generalization (now largely replaced by Batch Norm).

Overlapping Pooling

Uses stride smaller than pool size (stride 2, pool 3×3), providing richer features than non-overlapping pooling.

VGG Design Principles

  • All conv filters are 3×3, stride 1, same padding — uniform throughout
  • Max pooling is 2×2, stride 2 — halves spatial dimensions
  • Channels double after each pooling block: 64 → 128 → 256 → 512 → 512
  • ReLU activation after every conv layer
  • Three fully connected layers at the end: 4096 → 4096 → 1000
💡
Why two 3×3 convolutions instead of one 5×5?

Two stacked 3×3 conv layers have the same receptive field as one 5×5 layer, but with fewer parameters (2×3×3=18 vs 5×5=25 per channel) and an extra non-linearity (ReLU). VGG showed this simple insight scales to very deep networks.

Residual Networks (ResNet)

🔥 Hot Topic 2023 ✓ 2024 ✓

Proposed by Kaiming He et al. (Microsoft Research) in 2015, ResNet introduced skip connections (residual connections) that allow training of extremely deep networks (50, 101, 152 layers) without degradation. It won ILSVRC-2015 with a top-5 error of only 3.57%.

2015Year
34–152Depths
~25MParams (ResNet-50)
3.57%Top-5 Error

The Problem: Degradation

As networks get deeper, accuracy degrades — not because of overfitting, but because of the vanishing gradient problem. Gradients become too small to update early layers. ResNet solves this with skip connections.

The Residual Block

x (input)
→
CONV + BN + ReLU
→
CONV + BN
→
+ x (skip)
→
ReLU
F(x) + x = H(x)
Residual Learning H(x) = F(x) + x

Instead of learning H(x) directly, the block learns F(x) = H(x) − x
If optimal mapping is identity: F(x) → 0, trivially achievable
Skip connection allows gradient to flow directly → no vanishing gradients!

Why Skip Connections Help

  • Gradient highway: Gradients flow directly from output to early layers without shrinking
  • Identity learning: If a layer is not needed, it can learn to output 0 (making H(x) = x)
  • Ensemble effect: Acts like training many different depth networks simultaneously

Bottleneck Block (ResNet-50+)

For deeper ResNets, a 3-layer bottleneck design reduces computation:

Bottleneck Design 1×1 CONV (reduce depth 256→64) → 3×3 CONV → 1×1 CONV (expand 64→256)

The 1×1 convolutions act as dimensionality reduction/expansion
📝
Exam Key Points for ResNet

Always mention: (1) Skip/residual connections, (2) Solves vanishing gradient problem, (3) H(x) = F(x) + x formula, (4) Batch Normalization is used after each conv, (5) Can train 100+ layer networks effectively.
